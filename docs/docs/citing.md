# :bookmark: Citing Posters.science

If you use Posters.science in your research or reference it in a publication, please cite the platform and any relevant tools.

## :page_facing_up: Platform

> O'Neill, J., Soundarajan, S., Portillo, D., & Patel, B. (2026). Posters.science: A free, open-source platform for sharing, discovering, and citing scientific posters. Available at [https://posters.science](https://posters.science).

## :robot: poster2json (extraction tool)

> O'Neill, J., Soundarajan, S., Portillo, D., & Patel, B. (2026). poster2json: Convert scientific posters to structured JSON metadata using Large Language Models. Zenodo. [https://doi.org/10.5281/zenodo.18320010](https://doi.org/10.5281/zenodo.18320010)

## :scroll: Poster JSON Schema

> FAIR Data Innovations Hub. (2026). Poster JSON Schema: A JSON schema for machine-actionable and FAIR posters. Available at [https://github.com/fairdataihub/poster-json-schema](https://github.com/fairdataihub/poster-json-schema).

## :memo: BibTeX

```bibtex
@misc{posterscience2026,
  author    = {O'Neill, James and Soundarajan, Sanjay and Portillo, Dorian and Patel, Bhavesh},
  title     = {Posters.science: A free, open-source platform for sharing, discovering, and citing scientific posters},
  year      = {2026},
  url       = {https://posters.science},
  note      = {FAIR Data Innovations Hub}
}

@misc{poster2json2026,
  author    = {O'Neill, James and Soundarajan, Sanjay and Portillo, Dorian and Patel, Bhavesh},
  title     = {poster2json: Convert scientific posters to structured JSON metadata using Large Language Models},
  year      = {2026},
  doi       = {10.5281/zenodo.18320010},
  publisher = {Zenodo}
}
```

::: tip
If you shared a poster through Posters.science and received a DOI, you can cite that specific poster using the DOI assigned by Zenodo or Figshare. The DOI is shown on the poster's record page.
:::
