## About

This repository contains the documentation for posters.science.

## Developer Instructions

### Prerequisites

This project uses `yarn` as the package manager.

```bash
npm install -g yarn
```

### Run Locally

```bash
git clone https://github.com/fairdataihub/docs.posters.science.git
cd docs.posters.science
yarn install
yarn dev
```

### Build Locally

```bash
yarn docs:build
```
